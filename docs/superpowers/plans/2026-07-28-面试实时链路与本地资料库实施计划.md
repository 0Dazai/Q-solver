# 面试实时链路与本地资料库 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 补齐屏幕捕获隔离、实时面试稳定性、本地 Markdown 资料检索、可选云向量增强和对应前端工作区。

**Architecture:** 保留 Wails 单进程架构，以小型接口逐步拆分现有 `interview.Manager`。本地 SQLite FTS5 是必需检索路径，云向量实现为可选适配器；回答协调器统一完成检索、上下文构建、抢占和流式事件。

**Tech Stack:** Go 1.24、Wails 2、Vue 3、Pinia、Vite、Windows WASAPI、SQLite FTS5、Figma。

## Global Constraints

- 当前源码根目录为 `D:\work\项目工作区\Q-solver-1.0.0\Q-solver-1.0.0`。
- `build\bin\Q-Solver.exe` 更新前必须保存原哈希和回滚副本。
- 普通最小化不得使用 `WindowHide`；F9 保持屏幕捕获隔离语义。
- 原始资料只读；Markdown、索引和元数据默认完全本地。
- 云向量功能默认关闭，失败时回退本地 FTS。
- 生产代码修改遵循测试先行；测试、构建和人工验证分别记录。
- 项目当前不是 Git 仓库，计划中的提交步骤替换为就近变更记录和备份检查。
